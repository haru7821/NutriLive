# 네이버 블로그 발행 가이드

## 구조

`scripts/gen-naver-posts.mjs`가 `data/recipes.js`에서 발행용 초안을 자동 생성한다.
결과물은 `naver/drafts/<슬러그>.txt` — 제목·본문·재료·조리단계·팁·장보기(있으면)·태그까지
네이버 에디터에 그대로 복사·붙여넣기 하면 되는 완성 텍스트다.

**카드 이미지(`assets/cards/<슬러그>.png`)는 대표이미지일 뿐, 조리 단계 전문은 이 텍스트에 있다.**
카드=표지, 초안=본문 — 두 파일을 함께 써야 한 편의 발행글이 완성된다.

## 발행 방법

1. `node scripts/gen-naver-posts.mjs` 실행 (새 레시피만이면 `--only="요리명"`)
2. `naver/drafts/<슬러그>.txt` 열기
3. 네이버 블로그 에디터에서:
   - 대표이미지로 `assets/cards/<슬러그>.png` 업로드
   - `[제목]` 줄을 제목란에, 나머지 본문을 그대로 붙여넣기
   - 맨 아래 `추천 태그`를 태그 입력란에 나눠 입력
4. 발행 후 `naver/published.md`(있으면)에 발행일·URL 기록 — 추적용

## 컴플라이언스 체크 (발행 전 필수)

docs/COMPLIANCE.md와 동일 기준:
- 질병명 + 효능 동사 조합 없음
- 수치는 「추정 참고치」 표기 (템플릿에 기본 포함됨)
- 어필리에이트 링크 포함 시 「광고 포함」 고지 (템플릿에 기본 포함됨)
- 전문가 상담 안내 문구 포함 (템플릿에 기본 포함됨)

## 참고

- 예약 발행(다음 달 이후 `mon`) 레시피는 기본적으로 초안이 생성되지 않는다 — 발행월이 되면 자동 포함.
  미리 준비하려면 `--only="요리명"`으로 개별 생성.
- 인스타그램 등 SNS 자동 업로드는 별도 설정(Graph API 등)이 필요해 아직 미구현 — docs/CONTENT_ROUTINE.md 참고.
