# NutriLive 주간 레터 — 발행 가이드

## 구조

`vol01-no1.html`이 마스터 템플릿이자 제1호입니다.
이메일 클라이언트 호환을 위해 **테이블 레이아웃 + 인라인 스타일**로 작성되어 있습니다
(웹폰트는 메일에서 대부분 무시되므로 Georgia/명조 계열 폴백을 씁니다).

매주 바꿀 곳은 `✂️` 주석이 붙은 세 블록뿐입니다:

1. **① 이번 주 레시피** — 요리명·나트륨·시간, 서너 문장 요약, recipes.html 링크
2. **② 해외에서 온 각주** — 큐레이션 아티클 한 편의 핵심 문단 요약 + 링크
3. **③ 이번 주 장보기 팁** — 한 문단짜리 실전 팁 (컴플라이언스: 질병명+효능 표현 금지)

## 발송 방법

1. 스티비/메일리 등 발송 도구에서 「HTML 직접 입력」 모드 선택
2. 해당 호 HTML 파일 내용 전체를 붙여넣기
3. 테스트 발송으로 모바일 메일앱 렌더링 확인 후 발송
4. 발송한 호는 `newsletter/vol01-no2.html`처럼 번호를 올려 저장(아카이브)

구독자 명단: Formspree 대시보드(주간 레터 구독 신청 수집분)에서 내보내기.

## 컴플라이언스 체크 (발송 전 필수)

- [ ] 질병명 + 효능 동사 조합 없음 ("~에 좋다/치료/개선" 금지)
- [ ] 수치는 「추정 참고치」 표기
- [ ] 전문가 상담 안내 문구 포함 (판권 블록에 기본 포함됨)
- [ ] 수신거부 안내 포함 (판권 블록에 기본 포함됨)
