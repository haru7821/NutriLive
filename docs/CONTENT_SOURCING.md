## 2. 정보 획득 경로

### A. 공개 API · 오픈 데이터 (자동화 가능 — 최우선)

| 소스 | 내용 | 비용 |
|---|---|---|
| **Sakenowa(さけのわ) API** | 사케 브랜드·양조장·풍미 데이터 공개 API | 무료 |
| **라쿠텐 상품검색 API** | 사케·위스키 실시간 판매가 (시세 근사치) | 무료 (어필리에이트 겸용) |
| 일본 국세청 주류 통계 | 양조장 면허·출하량 통계 | 무료 공개 |
| 각종 경매 결과 (야후옥션 낙찰가 등) | 위스키 시세 데이터 | 공개 정보 집계 |

### B. 공식 발표 모니터링 (반자동 — RSS/알림 구축)

| 소스 | 방법 |
|---|---|
| 산토리·닛카·벤처위스키 등 공식 뉴스룸 | RSS / 페이지 변경 감지 도구 |
| **PR TIMES** (일본 최대 보도자료 플랫폼) | 「日本酒」「ウイスキー」 키워드 알림 — 신제품 정보의 원천 |
| 양조장·증류소 공식 X(트위터) | 리스트로 묶어 일 1회 확인 |
| 주류 온라인숍 입고·추첨 공지 (IMADEYA, 하세가와사케텐, 신카와야 등) | 메일매거진 구독 + 페이지 감지 |
| 골프장 공식 사이트 / 라쿠텐 GORA / GDO | 그린피·예약 오픈 정보 (어필리에이트 프로그램 겸용) |

### C. 직접 생산 (핵심 차별화 — 시간 투자처)

- **자체 테이스팅 노트**: 온라인 구매 가능한 보틀을 직접 시음 → 유일한 오리지널 콘텐츠. 무단 복제 불가능한 자산
- **번역·큐레이션**: 일본어 1차 소스를 한국어로 요약 정리 — *한국어 시장에서 이것 자체가 희소가치* (AI 번역 파이프라인으로 1인 운영 가능)
- **데이터 집계 콘텐츠**: 흩어진 공개 정보(추첨 일정, 그린피, 낙찰가)를 표·캘린더로 재구성 — 사실 데이터의 편집·구조화는 저작권 문제 없음

### D. 커뮤니티 소싱 (Phase 1부터)

- 뉴스레터 독자 제보 (입고 목격담, 라운드 후기) → 검증 후 게재 + 크레딧
- 향후 Discord 커뮤니티의 UGC → 우수 후기 본편 승격
- **효과**: 콘텐츠 비용 ↓ + 참여 락인 ↑ → 유료 전환 모수 확보

### E. 제휴 소싱 (Phase 2 이후)

- 양조장·증류소 인터뷰 (화상) — B2B 관계 구축의 시작점
- 주류 수입사·온라인숍 제휴: 신제품 정보 선공유 ↔ 노출
- 골프 예약 플랫폼 어필리에이트: 콘텐츠 → 예약 전환 수수료

## 4. 법적·윤리적 가이드라인

1. **전재 금지**: 타 매체 기사·사진은 링크+요약만. 보도자료(PR TIMES)는 인용 목적 게재 관행상 허용 범위 내 활용
2. **스크래핑**: robots.txt·이용약관 준수, 공개 API 우선, 과도한 요청 금지
3. **주류 표현**: 만 19세 이상 대상 명시, 음주 조장 표현 지양 (이미 사이트 푸터에 반영)
4. **어필리에이트 표기**: 제휴 링크에는 「광고/제휴 링크 포함」 명시 (스폰서드는 「PR」 표기)
