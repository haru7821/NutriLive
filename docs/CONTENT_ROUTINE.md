# 주간 콘텐츠 루틴

> 매주 월요일 자동 실행되는 루틴의 작업 정의서. CTO(Claude)가 이 체크리스트대로 콘텐츠를 추가하고 커밋한다.

## 주간 작업 (매주 월요일)

1. **레시피 1~2편 추가** (`data/recipes.js`)
   - 1인분 나트륨 추정치 필수, 코스(밥·면/국물/반찬/간식) 배분 고려
   - 셰프의 메모(팁) 1줄 — 저나트륨 조리 기술 위주
2. **해외 큐레이션 1건 추가** (index.html #global)
   - 출처 기관 명시, 전문 전재 금지(요약+출처)
   - 소재 풀: NKF·NIH·AHA(미국), 감염 시장(일본), EFSA·지중해식(유럽)
3. **컴플라이언스 검수** — docs/COMPLIANCE.md 체크리스트 통과 확인
   - 질병명+효능 동사 조합 금지 / "환자" 계열 단어 금지 / 수치는 참고치 표기
4. **주간 레터 생성** — `newsletter/vol01-noN.html` 작성 후 같은 내용을 `newsletter/latest.html`로 복사
   - latest.html이 푸시되면 발송 워크플로가 자동 실행 (내용 해시 중복이면 발송 안 함)
   - 화요일 09:00 KST 정기 크론도 있음 — 월요일 루틴에서 미리 푸시해 두면 화요일에 나감
5. **레시피 카드 이미지 생성** (`scripts/gen-recipe-cards.mjs`)
   - 사진 없이 브랜드 지면 스타일(나트륨 큰 수치+게이지, 코스별 라인아트, 재료 칩, 셰프의 메모)로
     1080×1080 카드를 자동 생성 — `assets/cards/<슬러그>.png`
   - 새 레시피 추가 직후 실행: `node scripts/gen-recipe-cards.mjs --only="요리명"` (전체는 인자 없이)
   - 레시피 펼침 화면의 「카드 이미지 보기」 링크로 연결됨. 네이버 대표이미지·SNS 공유용으로 그대로 사용.
6. **장보기 메모(어필리에이트) 갱신** — 매주 월요일 10:00 KST 알림(CTO 세션 Routine)이
   이번 주 레시피 재료 기반 상품 목록을 뽑아 GM에게 쿠팡 파트너스 링크 생성을 요청.
   GM이 링크를 주면 `js/config.js`의 AFFILIATE_LINKS 교체 (미응답 시 기존 링크 유지).
7. **커밋·푸시** → 자동 배포

## 월간 작업 (매월 1일, Actions 자동)

- 식약처 DB 갱신 (`update-foods.yml` — MFDS_API_KEY 시크릿, 가동 중)

## 주간 레터 발송 (자동)

- `send-newsletter.yml` — MailerLite API로 `newsletter/latest.html`을 구독자 그룹에 발송
- 트리거: latest.html 푸시 / 매주 화요일 09:00 KST 크론 / 수동
- 구독자 0명이면 조용히 건너뜀 · 같은 내용 재발송 방지(해시) 내장
- 필요 시크릿: MAILERLITE_API_KEY

## 콘텐츠 백로그 (소재 저장소)

- 레시피: 저염 김치볶음(묵은지 헹굼법), 무염 버섯 육수 큐브, 저염 잡채, 콩나물국 맑게
- 큐레이션: 미국 저나트륨 라벨 규정(FDA "low sodium" 기준), 일본 저단백밥 시장, 영국 소금 저감 정책(업계 자율 목표제), 대만 저염 간장 시장
- 도구: 외식 메뉴 나트륨 추정표, 배달앱 저염 주문 문구 모음
