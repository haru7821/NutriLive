# NutriLive 표현·규제 준수 가이드라인

> 목적: 콘텐츠·상품·마케팅 전반에서 의료법/식품표시광고법 리스크와 식약처 특수 분류 대상을 회피하고,
> "일반 소비자 대상 저나트륨 라이프스타일 매체"라는 포지션을 일관되게 유지한다.
> **사이트에 올라가는 모든 문장은 이 문서를 기준으로 검수한다.**

---

## 1. 포지셔닝 원칙

| | ❌ 하지 않는 것 | ✅ 하는 것 |
|---|---|---|
| 대상 | 특정 질환자·환자 지칭 | "나트륨·칼륨·인이 신경 쓰이는 분" 등 일반 소비자 |
| 콘텐츠 | 의학적 조언·진단·치료법 제시 | 일반적 식생활 정보 제공 + 전문가 상담 권고 |
| 상품 | 환자용 식품·치료 효과 표방 | 일반식품의 영양성분 스펙만 소구 |

## 2. 금지 표현 → 대체 표현

| ❌ 금지 | ✅ 대체 |
|---|---|
| 투석 환자, 신부전 환자, 환자식 | 신장 건강이 신경 쓰이는 분, 저나트륨 식생활 |
| 치료, 개선, 예방에 효과 | (효능 표현 자체를 쓰지 않음 — 성분 수치만 기재) |
| ○○병에 좋은 음식 | 나트륨 ○mg의 저나트륨 레시피 |
| 의사가 권하는 / 처방 식단 | 국내외 공공기관 자료 기반 정보 (출처 링크) |
| 신장 기능을 지켜주는 | 나트륨을 줄인 / 인산염 첨가물이 없는 |

**규칙**: 신체 장기·질병명과 "효과·개선·보호" 류 동사를 한 문장에 넣지 않는다. 사실(성분 수치·조리법·출처)만 말한다.

## 3. 법적 근거와 회피 설계

### 식품표시광고법 제8조 (부당한 표시·광고 금지)
- 일반식품에 질병 예방·치료 효능이 있다고 인식할 우려가 있는 표시·광고 금지.
- → 마켓의 모든 제품은 **일반식품**으로 취급하고, "나트륨 500mg 이하" 같은 **객관적 수치 기준**만으로 큐레이션·소구한다.

### 특수의료용도식품 (식약처 인허가 대상) 회피
- "환자용 식품"으로 표방하는 순간 제조·표시 기준과 인허가 대상이 된다.
- → 자체 상품 개발 시에도 일반식품 카테고리(즉석조리식품·과자 등)로 기획하고, 질환 연관 마케팅을 하지 않는다.

### 의료법 (의료행위·의료광고)
- 개인별 진단·처방으로 해석될 수 있는 1:1 식단 지도는 하지 않는다.
- 모든 페이지 푸터에 disclaimer 고정: 정보 제공 목적 / 의학적 조언 아님 / 의사·임상영양사 상담 권고.

### 건강기능식품 오인 방지
- "기능성", "인증" 등의 단어를 일반식품에 쓰지 않는다.

## 4. 콘텐츠 운영 수칙

1. **출처 명시**: 해외 자료 큐레이션은 반드시 원문 기관·링크 명시 (WHO, 각국 공공기관, 학회 공개 자료). 전문 번역 전재는 금지 — 요약 + 링크만.
2. **수치 표기**: 영양성분은 "참고치"임을 명시. 계산 도구 제공 시에도 "일반적 정보이며 개인별 권장량은 전문가와 상담" 문구 병기.
3. **후기·리뷰 관리**: 사용자 후기에 질병 효능 언급이 들어오면 게재 전 편집·비노출 (광고주 콘텐츠일 경우 특히 엄격히).
4. **제휴·광고 표기**: 어필리에이트 링크·스폰서드에 「광고 포함」 표기.

## 5. 검수 체크리스트 (게시 전)

- [ ] "환자" 계열 단어가 없는가?
- [ ] 상품 소개가 성분 수치·조리 편의만 말하는가?
- [ ] 출처 링크가 있는가? (큐레이션 콘텐츠)
- [ ] disclaimer가 페이지에 노출되는가?
