# "NutriLive" 상표 출원 전 유사 상표 검색 리포트

- 작성일: 2026-08-05
- 작성: CFO 겸 법무 담당 (내부 검토용)
- 대상 상표: **NutriLive** (문자) 및 **그릇+잎사귀 도형 + "NutriLive" 결합상표**
- 예정 사용 범위: 저나트륨·저칼륨·저인 식생활 정보 웹사이트/앱, 큐레이션 온라인 마켓(일반식품), 뉴스레터

> **중요 고지**: 본 리포트는 공개 웹 검색 기반의 1차 스크리닝이며, KIPRIS(키프리스) 검색 결과 페이지는 본 조사 환경에서 직접 접근이 차단(HTTP 403)되어 **키프리스 원문 확인이 이루어지지 않았습니다**. 아래 모든 판단은 잠정적이며, **출원 전 반드시 KIPRIS 재검색 및 변리사 자문을 거쳐야 합니다.**

## 1. 동일·유사 상표 검색 결과

### 1-1. "NutriLive / 뉴트리라이브" 동일 명칭

국내 웹 검색에서는 "뉴트리라이브"라는 한국 상표·브랜드의 존재가 확인되지 않았습니다. 다만 **해외에는 동일 명칭 브랜드가 다수 실존**합니다.

| 명칭 | 지역/성격 | 비고 |
|---|---|---|
| Nutrilive UK | 영국, 개인 맞춤 영양·피트니스 플랜 서비스 | X(트위터) @NutriliveUK 운영 |
| Nutrilive Argentina | 아르헨티나, 뷰티·퍼스널케어 | Facebook 페이지 운영 |
| NutriLive (코스타리카) | 반려견용 식욕촉진 오일 등 | Walmart 코스타리카 온라인몰 입점 확인 |
| nutrilive.store / nutrilive.shop | 커머스 도메인 이미 선점됨 | .store는 접근 차단으로 상세 미확인 |

- **USPTO(미국)**: "NUTRILIVE" 자체의 미국 등록은 이번 검색에서 직접 확인되지 않았으나, 매우 유사한 **"NUTRILIVING"이 2건 등록**되어 있음(등록 4479075: 가공식품류 / 등록 4481911: 건강정보 웹사이트·온라인 스토어 — 우리 사업과 서비스 내용이 상당히 겹침). 인도에는 "NUTRILIV FORTE" 출원 이력(철회됨)도 존재.
- **EUIPO/WIPO**: 검색엔진 경유로는 확정 불가. 해외 진출 계획이 생기면 EUIPO(euipo.europa.eu), WIPO Global Brand Database(wipo.int)에서 직접 검색 필요.
- 시사점: **국내 출원에는 해외 미등록 브랜드가 직접 장애가 되지 않으나**, 해외 진출·글로벌 도메인/SNS 계정 확보 관점에서는 이미 혼잡한 이름임.

### 1-2. NUTRILITE / 뉴트리라이트 (암웨이) — 최대 리스크

- 1934년 미국에서 시작된 세계 최대급 비타민·건강기능식품 브랜드로, 한국암웨이가 1991년부터 국내에서 대규모로 판매 중. 서브브랜드 "n by Nutrilite"도 국내 전개 중.
- 미국 USPTO에도 다수 등록(예: 등록 3545103) 확인. 국내에서도 한국암웨이/Alticor 계열이 다수 류에 걸쳐 등록해 두었을 것이 사실상 확실함(키프리스에서 권리자 "암웨이", "Alticor" 검색으로 확인 필요).
- **호칭 비교: "뉴트리라이브" vs "뉴트리라이트" — 5음절 중 마지막 1음절의 종성급 차이(브/트)에 불과.** 한국 상표 실무는 외관·호칭·관념 중 **호칭 유사를 가장 중시**하며, 이 정도 차이는 유사로 판단될 가능성이 높다고 봐야 함.
- 관념: 둘 다 "Nutri-(영양)" + 유사 어미로, 영양·건강 관련 상품에서 관념상으로도 근접.
- 결론(잠정): **식품·건강 관련 상품(특히 05류, 29/30류, 32류)에서는 NUTRILITE와의 유사를 이유로 한 거절(상표법 제34조 제1항 제7호) 또는 이의신청·무효심판 리스크가 매우 높음.** 자세한 분석은 2장 참조.

### 1-3. "뉴트리(Nutri-)" 접두 상표의 혼잡도

식품·건강기능식품 분야에서 "뉴트리" 접두 브랜드가 이미 다수 활동 중임이 확인됨.

| 브랜드 | 운영사/성격 |
|---|---|
| 뉴트리원(NUTRIONE) | 2012년 설립, 건강기능식품 전문(비비랩 등 서브브랜드) |
| 뉴트리코어(NUTRICORE) | 건강기능식품, "네이버 41관왕" 마케팅 |
| 뉴트리디데이(Nutri D-DAY) | 건강기능식품, "올해의 브랜드 11년 연속 1위" 주장 |
| 뉴트리라이트(NUTRILITE) | 암웨이 |
| (그 외) 뉴트리 관련 다수 | 키프리스에서 "뉴트리" 접두 검색 시 수십~수백 건 예상 |

시사점 (양면적):
- (유리) "Nutri/뉴트리"는 식품 분야에서 **식별력이 약한 관용적 접두어**로 취급될 여지가 있어, 심사관이 "뉴트리" 부분보다 뒷부분("라이브" vs "라이트" 등)을 비교 대상으로 삼을 수 있음. 그러나 우리 경우 뒷부분조차 NUTRILITE와 1음절 차이라 이 논리가 오히려 불리하게 작동.
- (불리) 접두가 혼잡하다는 것은 그만큼 선등록 장애물이 많고, 등록되더라도 권리 범위가 좁다는 뜻.

### 1-4. KIPRIS 직접 확인 시도

- `kipris.or.kr` 및 검색 결과 URL 접근 시 HTTP 403으로 차단되어 원문 확인 실패(해외/프록시 IP 차단으로 추정).
- **필수 후속 조치**: 국내 네트워크에서 KIPRIS 상표 검색으로 다음을 직접 조회할 것.
  - 검색어: `뉴트리라이브`, `NUTRILIVE`, `뉴트리라이트`, `NUTRILITE`, `뉴트리*`(접두 와일드카드), `NUTRI*`
  - 유사군코드 기준: G0301(건강기능식품), 각 식품 유사군, S류(서비스) 유사군
  - 권리자 검색: 한국암웨이, Alticor Inc.

## 2. 유사 판단 분석

### 2-1. 판단 기준

상표 유사는 **외관·호칭·관념**을 전체적·객관적·이격적으로 관찰하되, 국내 실무상 **호칭이 가장 중요한 기준**입니다. 아울러 상품 유사(유사군코드)와 결합하여 등록 가능성이 판단됩니다.

### 2-2. NutriLive vs 주요 발견 상표

### 2-4. 저명상표 논점 — 지정상품이 달라도 거절될 수 있는가

- **상표법 제34조 제1항 제9호**: 주지상표와 동일·유사 + 상품 동일·유사 → 거절.
- **제34조 제1항 제11호**: **저명상표**의 경우 ① 혼동 우려 또는 ② 식별력·명성의 손상(희석화) 우려가 있으면 **지정상품이 다르더라도** 거절될 수 있음. 아울러 제12호(수요자 기만) 병행 적용 가능.
- NUTRILITE는 국내 30년 이상 대량 판매·광고된 브랜드로, 최소한 건강기능식품 수요자 사이에서 **주지, 나아가 저명으로 인정될 가능성을 배제할 수 없음**. 저명 인정 시:
  - 09류(앱), 35류(쇼핑몰), 41류(정보제공)처럼 상품이 달라도 "영양·건강" 콘셉트가 겹치는 우리 서비스는 출처 혼동·기만 우려가 인정되기 쉬운 구도.
  - 즉 **"식품이 아니라 정보 서비스니까 괜찮다"는 논리는 안전하지 않음.**
- 다만 저명성 인정은 엄격하며(일반 대중 기준), NUTRILITE가 '주지' 수준에 그친다고 판단되면 비유사 상품군에서는 등록 여지가 있음. **이 경계 판단이야말로 변리사 자문이 필요한 핵심 쟁점.**

## 3. 결론 및 대안 전략

### 3-1. 류별 등록 가능성 종합 (잠정)

| 류 | 평가 |
|---|---|
| 29류·30류 (식품) | **위험 높음** — NUTRILITE 호칭 유사로 거절 가능성 상당. 등록되더라도 이의신청·무효 리스크 |
| 35류 (쇼핑몰·유통) | **위험** — 식품 소매 견련성 + 저명성 논점 |
| 09류·41류 (앱·정보제공) | **경계선** — 상품 비유사 논리로 등록 여지는 있으나 제34조 1항 11호·12호 리스크 잔존 |
| 05류 (건기식) | **사실상 불가** — 출원 비권장 |

**종합 의견(잠정): 문자상표 "NutriLive" 단독으로 식품·커머스 영역 출원을 강행하는 것은 비추천.** 거절 시 관납료 손실은 크지 않으나(류당 5만원 내외), 이미 사이트·마켓을 런칭한 뒤 이의신청·침해 경고를 받는 시나리오가 사업상 최악이므로, 출원 전 브랜드 전략 자체를 재검토할 필요가 있음.

### 3-2. 대안 전략

1. **결합상표(도형 중심) 출원**: "그릇+잎사귀" 도형 + 문자 결합으로 출원하면 전체 관찰상 등록 가능성이 다소 올라감. 다만 **호칭은 여전히 "뉴트리라이브"로 나므로 근본 해결책이 아니며**, 문자 부분 유사를 이유로 거절될 수 있음. 도형 마크 단독(문자 없는 로고) 출원은 안전한 보완책.
2. **한글 표기 차별화**: "뉴트리라이브" 대신 다른 호칭 유도(예: "누트리리브") — 실효성 낮음. 수요자는 어차피 영문을 "뉴트리라이브"로 읽음. 비추천.
3. **브랜드명 일부 변경 (권장 검토)** — "Nutri" 접두 자체가 혼잡하므로 접두 또는 어미를 바꾸는 방안:
   - **LowSaltLive / 로솔트리브**: 저염 정체성 직접 표현(단, 성질표시로 식별력 심사 주의)
   - **NutriVerde / 뉴트리베르데**: 어미를 3음절로 늘려 NUTRILITE와 호칭 거리 확보
   - **SaluLive / 살루리브**, **MildTable / 마일드테이블**: "뉴트리" 접두 탈피형 — 충돌 표면적 최소화
   - 후보 확정 전 각 후보에 대해 키프리스 재검색 필수.
4. **단계적 출원**: 충돌 위험이 상대적으로 낮은 **41류(정보제공)·09류(앱)부터 선출원**해 심사관 반응을 확인한 뒤 29/30/35류를 후속 출원하는 방법. 다만 후속 출원 사이에 제3자 선점 위험이 있음.
5. **선사용·공존 검토**: 암웨이 측 국내 등록의 지정상품을 정밀 분석해 비어 있는 상품군을 특정하는 작업 — 변리사 의뢰 사항.

### 3-3. 셀프 출원 절차 요약 (진행 결정 시)

1. **특허고객번호 발급**: 특허로(patent.go.kr)에서 온라인 신청 (무료, 인증서 필요)
2. **KIPRIS 재검색**: 위 1-4의 검색어·유사군코드로 최종 확인
3. **전자출원**: 특허로 로그인 → [국내출원] → [상표] → 상표등록출원서 작성 (지정상품은 고시명칭 사용 권장)
4. **비용(전자출원, 류당)**:
   - 출원료: 고시명칭만 사용 시 **46,000원/류**, 비고시 명칭 포함 시 52,000원/류 (지정상품 20개 초과 시 가산)
   - 등록료(10년): **약 210,120원/류** (5년 분할납부 가능)
   - 예: 4개 류(09·29·30·35) 출원 시 출원료 약 18.4만원, 전건 등록 시 등록료 약 84만원
5. **심사 기간**: 통상 6개월~1년 이상. 거절이유통지 수령 시 2개월 내 의견서·보정서 제출 (이 단계에서는 변리사 선임 강력 권장)

### 3-4. 권고 액션

1. 국내 네트워크에서 **KIPRIS 정밀 재검색** (NUTRILITE 국내 등록의 류·지정상품 전수 확인 포함)
2. 검색 결과를 들고 **변리사 정식 자문** (쟁점: NUTRILITE의 주지·저명성 수준, 호칭 유사 판단, 류별 회피 설계)
3. 자문 결과에 따라 (a) 현 명칭 + 도형 중심 출원, (b) 브랜드명 변경 후 출원 중 택일
4. 병행하여 **도메인·SNS 핸들 선점 현황**(nutrilive.store/.shop 등 이미 타인 선점)도 브랜드 결정 요소로 반영
