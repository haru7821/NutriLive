## 3. 최종 추천 Top 2

### 1위: SlowSalt (슬로솔트)

1. **선사용 청정 + 콘셉트 직결의 균형점.** 동일 명칭 사용자가 검색상 없고, 조어이면서도 "저염(salt를 천천히)"과 "슬로푸드(계간지 톤)"를 한 단어에 담는 유일한 후보.
2. **Saltwise가 증명한 반례**: 같은 방향의 직관형 이름은 이미 선점됨. SlowSalt는 같은 관념을 조어로 비켜간 형태라 식별력과 회피가 동시에 성립.
3. 리스크 관리 포인트: ① 영국 Slow Sodium™(의약품)과의 관념 근접 — 05류를 지정하지 않고 건기식 진출 계획이 없는 우리 구조에서는 통제 가능, ② 한글 표기 "슬로솔트" 조기 고정, ③ KIPRIS에서 `솔트` 계열 선등록 확인 필수.

### 2위: Slowspoon (슬로스푼)

1. **법적 구조가 가장 깨끗함.** 맛·염도 기술어가 전무한 완전 조어 — 성질표시 거절 리스크가 후보군 중 최소이고, 향후 커머스(29/30/35류) 확장 시에도 이름이 발목을 잡지 않음.
2. 저염 정체성은 태그라인·에디토리얼이 전달하면 되며, 이름은 그릇처럼 비워두는 전략. NutriLive → NUTRILITE 사태의 교훈(이름에 카테고리를 욱여넣으면 혼잡 지대로 들어간다)에 가장 충실한 선택.
3. 리스크 관리 포인트: "스푼" 포함 국내 선등록(외식·미디어에 흔한 요소) KIPRIS 전수 확인.

**백업**: Umamist (두 후보가 KIPRIS/도메인에서 좌초 시). **Unsalted는 브랜드명 대신 콘텐츠 자산으로**: 매거진 특집명·칼럼명("Unsalted", "언솔티드 에세이") 같은 기술적 사용은 자유롭고, 에디토리얼 톤의 강점만 취할 수 있음 — 슴슴을 코너명으로 살리는 기존 권고와 같은 구조.

## 5. 이번 조사의 한계 (반드시 읽을 것)

1. **KIPRIS 3회 연속 미확인**: 국내 선등록 관련 모든 평가는 실사용 웹 검색 기반 추정. **KIPRIS 검색 완료 전 어떤 후보도 확정 금지.**
2. **USPTO/EUIPO 직접 검색 불가**: Unsalted 외 후보의 미국·유럽 등록 여부는 전부 "미확인". 웹 검색에서 안 나왔다는 것은 "없다"의 증거가 아님 — 특히 Mildly처럼 일반 단어형은 탐지 실패 확률이 구조적으로 높음.
3. **검색 리전 한계**: 미국 리전 검색엔진만 사용 가능, 네이버 차단. 국내 로컬 상호(네이버 플레이스·스마트스토어)의 "슬로솔트/슬로스푼" 류 소규모 선사용은 누락됐을 수 있음.
4. **도메인·SNS 전 항목 미확인**: WHOIS/DNS/인스타그램 접속 차단. 체크리스트 1단계에서 10분 내 수동 확인 가능.
5. **검색 횟수 제한**: 후보당 2~3회로 제한 조사. Slowspoon(신규)은 1회 검색만 수행했으므로 확정 전 추가 검색 권장.

> **재고지: 본 문서의 모든 상표 유사·식별력·등록 가능성 평가는 비전문가의 잠정 의견이며, 최종 판단은 반드시 변리사 자문을 통해 확정해야 합니다.**
