# 인스타그램 게시 가이드

## 구조

`scripts/gen-instagram-posts.mjs`가 `data/recipes.js`에서 캡션을 자동 생성한다.
결과물은 `instagram/drafts/<슬러그>.txt` — 훅 문장·설명·저장 유도 문구·(어필리에이트 있으면) 광고 고지·해시태그까지
인스타 앱에 그대로 복사·붙여넣기 하면 되는 완성 캡션이다.

**대표이미지는 `assets/cards/<슬러그>.png` 그대로 쓴다.** 조리 단계 전문이 카드 이미지 안에 이미
들어 있어서, 캡션에는 전체 재료·단계를 다시 나열하지 않고 훅과 저장 유도만 담았다 — 인스타 캡션은
길수록 참여도가 떨어지고, "더 보기"로 잘리는 첫 125자 전후에 핵심 수치를 배치하는 게 유리하다.

## 게시 방법 (수동 — 자동 업로드 미구현)

1. `node scripts/gen-instagram-posts.mjs` 실행 (새 레시피만이면 `--only="요리명"`)
2. `instagram/drafts/<슬러그>.txt` 열기
3. 인스타그램 앱에서:
   - 사진으로 `assets/cards/<슬러그>.png` 업로드
   - 캡션란에 `.txt` 내용 그대로 붙여넣기
4. 게시 후 `instagram/published.md`(있으면)에 게시일·URL 기록 — 추적용

## 릴스로 확장하려면

카드 이미지 여러 장(재료 → 1단계 → 2단계 → … → 완성 나트륨)을 슬라이드쇼로 이어 붙이면
정지 이미지보다 노출이 넓은 릴스 소재가 된다. 현재는 카드 1장에 전체 단계가 들어있는 구조라
릴스용으로는 별도 분할 이미지가 필요 — 수요가 있으면 `gen-recipe-cards.mjs`에 슬라이드 분할
옵션을 추가할 수 있다.

## 컴플라이언스 체크 (게시 전 필수)

docs/COMPLIANCE.md와 동일 기준:
- 질병명 + 효능 동사 조합 없음 ("환자/치료/예방/개선" 등 금칙어)
- 수치는 「추정 참고치」 표기 (템플릿에 기본 포함됨)
- 어필리에이트 매칭 시 「광고」 고지 (템플릿에 기본 포함됨)
- 전문가 상담 안내 문구 포함 (템플릿에 기본 포함됨)
