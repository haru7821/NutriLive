# KANPAI LINKS — 乾杯リンクス

> 일본 사케 · 위스키 · 골프 큐레이션 사이트 & 1인 기업 프로젝트

낮에는 명문 코스의 페어웨이, 밤에는 사카바 카운터. 일본의 술 문화와 골프를 하나의 여정으로 큐레이션하는 미디어이자, 멤버십 기반 수익화를 목표로 하는 1인 기업 프로젝트입니다.

## 프로젝트 구조

```
├── index.html        # 메인 랜딩 (사케/위스키/골프 큐레이션 + 시그니처 투어)
├── membership.html   # 멤버십 요금제 + 수익 모델 + FAQ
├── css/style.css     # 디자인 시스템 (漆黒 Lacquer Black × 金 Gold 에디토리얼)
├── js/main.js        # 스크롤 리빌, 모바일 내비게이션
└── docs/
    └── BUSINESS_MODEL.md  # CFO 수익화 전략 리포트
```

## 기술 결정 (CTO 노트)

| 단계 | 스택 | 이유 |
|------|------|------|
| **Phase 1 (현재)** | 정적 HTML/CSS/JS + GitHub Pages | 인프라 비용 ¥0, 배포 즉시, SEO 유리. 콘텐츠로 트래픽 검증에 집중 |
| **Phase 2** | Next.js + Supabase(Auth/DB) + Stripe | 프리미엄 멤버십 결제·회원 전용 콘텐츠 게이팅 |
| **Phase 3** | + Discord 연동, 이메일 자동화(Resend), 예약 시스템 | 커뮤니티·투어·컨시어지 수익 확장 |

## 로컬 실행

빌드 도구가 필요 없습니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 수익 모델 요약

1. **멤버십 구독** — FREE / PREMIUM(₩9,900/월) / CONCIERGE(₩490,000/년, 한정)
2. **B2B 광고** — 양조장·증류소·골프장 스폰서드 콘텐츠
3. **커머스** — 제휴 어필리에이트 + 큐레이션 판매 수수료
4. **체험형** — 시그니처 투어 패키지, 온라인 마스터클래스

상세 전략은 [`docs/BUSINESS_MODEL.md`](docs/BUSINESS_MODEL.md) 참조.

## 법적 고지

- 만 19세 이상 대상 콘텐츠 (주류 정보 포함)
- 주류 통신판매는 한·일 양국 주류 판매 규제를 준수해야 하며, 직접 판매가 아닌 정보 제공·제휴 중개 모델을 기본으로 함
